# Yogi Tri Cahyono's Website

Personal website built with Jupyter Book and deployed to GitHub Pages.

## Domains and URLs

| Address | Purpose |
| --- | --- |
| [ygtc.me](https://ygtc.me/) | Primary custom domain, configured in `CNAME`. |
| [ygcahyono.github.io](https://ygcahyono.github.io/) | Default GitHub Pages hostname for this repository. |
| [ygtc.me/dashboard/](https://ygtc.me/dashboard/) | Dashboard path on the primary domain; not a subdomain. |

No custom subdomains are configured in this repository. The previous custom domain was `ygtc.online`.
