🦞 Clio

My WhatsApp AI assistant (NanoClaw). A reminder of what it can do.

💬 Ask anything

Claw group: just type. Other groups: start with @Clio

  • Web search and read pages, drive a browser
  • Read and write files in its folders
  • Set up recurring tasks ("every Monday 8am…")
  • Remembers context per group

🎙 Voice journal

Journal group

  • !j then a voice note → themed entry for today, with rating
  • !jy → same, for yesterday
  • !c then corrected text → replaces today's entry
  • Picks up reminders: "remind me to X on Y"
  • Nudges at 8 pm if there's no entry yet

✅ To-do

Any group

  • !todo buy milk → added, auto-categorised
  • !todo list → active items by category
  • !todo done 3 · !todo delete 3
  • !todo history → done in the last 7 days

🔖 Saved links

Any group

  • !save <url> [note] → save a link
  • !links → list saved links
  • !save search <query> · !save delete 3
  • !save export → all links as markdown

🎾 Tennis serve sheet

Tennis Bot group

  • Send a serve video (as a Document for full quality)
  • → six key moments: start, toss, trophy, racket drop, contact, landing, plus a checklist
  • Caption to change it: "compare with Djokovic", "only trophy"

☀️ Status & remote

"Good morning": any group · remote: Claw group only

  • "Good morning" → instant status reply
  • /remote-control → link to a Claude Code session on the Mac
  • /remote-control-end → stop it
